# 📊 Dashboard de Análise Financeira

## 📌 Sobre o projeto

Este projeto foi desenvolvido no Power BI com o objetivo de analisar dados financeiros por meio de gráficos e indicadores interativos.

O dashboard permite visualizar receitas, despesas e margem de lucro, facilitando a interpretação dos resultados financeiros.

## 📈 Indicadores financeiros

- **Total de Receitas:** 1,92 milhão
- **Total de Despesas:** 1,15 milhão
- **Margem de Lucro:** 39,96%

## 📊 Análises realizadas

- Análise de receitas por categoria
- Análise de despesas por setor
- Comparação de resultados por ano
- Visualização dos principais segmentos financeiros
- Identificação de indicadores financeiros

## 🛠️ Ferramentas utilizadas

- Microsoft Power BI
- Visualização de Dados
- Análise Financeira

## 🎯 Objetivo do projeto

Aplicar conhecimentos de análise de dados, desenvolver habilidades na criação de dashboards e aprimorar a interpretação de indicadores financeiros.
